# 📖 **Data Dictionary**

| Nama Kolom              | Tipe Data | Deskripsi                                                                            |
| :---------------------- | :-------: | :----------------------------------------------------------------------------------- |
| `age`                   | `float64` | Usia developer dalam satuan tahun.                                                   |
| `experience_years`      | `float64` | Total durasi pengalaman kerja profesional dalam hitungan tahun.                      |
| `daily_work_hours`      | `float64` | Durasi waktu yang digunakan untuk bekerja setiap hari.                               |
| `sleep_hours`           | `float64` | Durasi waktu istirahat tidur dalam satu hari.                                        |
| `caffeine_intake`       | `float64` | Jumlah konsumsi kafein harian dalam hitungan cangkir.                                |
| `bugs_per_day`          | `float64` | Jumlah kesalahan pada kode yang dihasilkan setiap hari.                              |
| `commits_per_day`       | `float64` | Jumlah riwayat pengiriman kode ke repositori dalam sehari.                           |
| `meetings_per_day`      | `float64` | Jumlah pertemuan yang harus dihadiri developer setiap hari.                          |
| `screen_time`           | `float64` | Total durasi waktu menatap layar perangkat digital harian.                           |
| `exercise_hours`        | `float64` | Durasi waktu untuk melakukan aktivitas fisik harian.                                 |
| `stress_level`          | `float64` | Skor tingkat stres dalam rentang 0 sampai 100.                                       |
| `burnout_level`         |  `int64`  | Variabel target yang menunjukkan tingkat burnout developer.                          |
| `work_sleep_ratio`      | `float64` | Rasio antara jam kerja dan waktu tidur developer.                                    |
| `screen_time_intensity` | `float64` | Intensitas penggunaan layar dibanding total jam kerja harian.                        |
| `commit_bug_ratio`      | `float64` | Rasio jumlah commit terhadap jumlah bug sebagai indikator efisiensi kerja developer. |
| `work_category`         |  `int64`  | Kategori tingkat keseimbangan antara beban kerja dan waktu istirahat developer.      |
